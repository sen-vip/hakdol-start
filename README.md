# ◆ 학돌시작

**행정실에서 시작한 실무 도구를 모은 학돌랩의 업무 시작페이지**입니다.

학교 행정실 직원이 실제 업무에서 쓰려고 만들고, 직접 쓰며 다듬고 있습니다. 작은책상에서 오늘 할 일을 정리하고, 지금 하려는 업무를 검색해 필요한 도구로 바로 이동할 수 있습니다.

## v0.5.4 업데이트

- 메인 브랜드 문구는 기존 문구를 그대로 유지했습니다.
- `계약·구매·공사` 카드를 다른 업무군과 같은 3열 그리드로 되돌려 모든 카드가 왼쪽부터 순서대로 배치되도록 수정했습니다.
- `품샷`, `세금계산서 저장`을 포함한 모든 카드의 가로폭을 동일하게 유지합니다.

## v0.5.3 업데이트

- 메인 문구를 `학교가 잘 돌아가도록, 행정실에서 직접 만든 도구들`로 바꾸고 학돌랩의 제작 이유를 더 선명하게 보여줍니다.
- 소개 문구에 `학교 행정실 직원이 실제 업무에서 쓰려고 만들고, 직접 쓰며 다듬는다`는 학돌랩의 성격을 반영했습니다.
- `계약·구매·공사` 도구 순서를 실제 업무 흐름에 가깝게 `품샷 → 계약콕검 → 계약서류 작성지원 → 세금계산서 저장 → 공사허브 → 보험콕검 → 버스콕검`으로 정리했습니다.
- 데스크톱에서 해당 업무군을 `3개 → 2개 → 2개` 카드 배열로 구성해 마지막 카드가 혼자 남지 않도록 다듬었습니다.
- 모바일·태블릿에서는 기존 2열/1열 반응형 구조를 유지합니다.

## v0.5.1 업데이트

- `세금계산서 저장` 카드에 **바로 다운로드**와 **설치 방법** 버튼을 함께 제공합니다.
- `바로 다운로드`는 GitHub Releases의 최신 `hakdol-tax-invoice-saver.zip` 파일로 연결합니다.
- `설치 방법`은 GitHub README로 연결합니다.

## v0.5.0 업데이트

- `품샷`을 공개 전환하고 `https://pumshot.onrender.com/`으로 바로 연결합니다.
- 품샷 카드에 첫 접속 시 서버가 깨어나는 동안 잠시 걸릴 수 있다는 안내를 추가했습니다.
- `업추비 3%`를 예산·회계 영역에 추가했습니다.
- `세금계산서 저장`을 계약·구매·공사 영역에 추가했습니다.
- 세금계산서 저장은 Chrome·Whale 확장프로그램임을 카드에서 구분하고, 현재는 GitHub 설치 안내로 연결합니다.
- 계약 업무군 이름을 `계약·구매·공사`로 다듬어 구매 도구의 위치를 더 명확하게 했습니다.
- 검색 예시에 `세금계산서`를 추가하고 관련 검색어를 보강했습니다.

## v0.4.2 업데이트

- `학교회계 예산현황판`을 현재 공개 버전 기준으로 학돌시작에 반영했습니다.
- 예산·회계 영역과 `자주 쓰는 도구`에서 바로 열 수 있습니다.
- 검색어 `예산`, `예산 잔액`, `예상잔액`, `사업관리카드`, `102-2` 등으로 예산현황판을 찾을 수 있습니다.
- 설명 문구를 `복잡한 학교예산을 시각화해 예산 현황·집행·예상 잔액을 더 쉽게 확인합니다.`로 정리했습니다.
- 예산현황판 갱신 시점을 `2026.09`로 반영했습니다.

## v0.4.1 업데이트

- `전국 학사일정`을 학돌시작에서 제거했습니다.
- `품샷`을 계약·공사·보험 영역에 추가했습니다.
- 품샷은 공개 링크 없이 `비공개` 상태로 표시되며 카드에서 외부 페이지로 이동하지 않습니다.
- 품샷 설명: 견적서 PDF를 바탕으로 품의서 본문과 에듀파인 업로드용 엑셀 작성을 돕는 도구입니다.

## v0.4.0 업데이트

### 학돌랩 브랜드 정립

- 상위 브랜드를 `학돌랩`으로 명확히 표시했습니다.
- 메인 슬로건을 `행정실에서 시작한 실무 도구`로 변경했습니다.
- 소개 문구에 `현직 행정실 직원이 실제 업무에서 겪은 불편에서 시작한다`는 제작 방향을 반영했습니다.
- 하단에 학돌랩의 제품 원칙 3가지를 추가했습니다.
  - 현장에서 시작합니다.
  - 한 번 한 일은 다시 하지 않습니다.
  - 도구는 일을 끝내야 합니다.

### 첫 화면 흐름 재구성

첫 화면을 다음 순서로 재배치했습니다.

1. 학돌랩 브랜드 소개
2. 작은책상
3. 업무 검색
4. 자주 쓰는 도구
5. 모든 업무 도구
6. 학교생활 도구
7. 작은 실험실
8. 학돌랩 제품 원칙

`작은책상`은 접거나 별도 페이지로 이동하지 않고 항상 펼쳐진 상태로 유지합니다.

### 검색 개선

- 검색창을 히어로에서 분리해 `작은책상` 바로 아래에 배치했습니다.
- 도구 이름 대신 `예산 잔액`, `공문 정리`, `준공 서류`, `보험`, `초과근무` 같은 업무 표현으로 찾을 수 있게 했습니다.
- 자주 쓰는 검색 예시를 바로 누를 수 있는 버튼으로 제공합니다.
- 검색 아래에 업무군 바로가기를 추가했습니다.
