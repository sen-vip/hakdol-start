# ◆ 학돌시작

**행정실에서 시작한 실무 도구, 학돌랩의 업무 시작페이지**입니다.

현직 행정실 직원이 실제 업무에서 겪은 불편을 작은 웹도구로 하나씩 해결합니다. 작은책상에서 오늘 할 일을 정리하고, 지금 하려는 업무를 검색해 필요한 도구로 바로 이동할 수 있습니다.

## v0.4.0 업데이트

### 학돌랩 브랜드 정립

- 상위 브랜드를 `학돌랩`으로 명확히 표시했습니다.
- 메인 슬로건을 `행정실에서 시작한 실무 도구`로 변경했습니다.
- 소개 문구에 `현직 행정실 직원이 실제 업무에서 겪은 불편에서 시작한다`는 제작 방향을 반영했습니다.
- 하단에 학돌랩의 제품 원칙 3가지를 추가했습니다.
  - 현장에서 시작합니다.
  - 한 번 한 일은 다시 하지 않습니다.
  - 도구는 일을 끝내야 합니다.

### 첫 화면 흐름 재구성

첫 화면을 다음 순서로 재배치했습니다.

1. 학돌랩 브랜드 소개
2. 작은책상
3. 업무 검색
4. 자주 쓰는 도구
5. 모든 업무 도구
6. 학교생활 도구
7. 작은 실험실
8. 학돌랩 제품 원칙

`작은책상`은 접거나 별도 페이지로 이동하지 않고 항상 펼쳐진 상태로 유지합니다.

### 검색 개선

- 검색창을 히어로에서 분리해 `작은책상` 바로 아래에 배치했습니다.
- 도구 이름 대신 `예산 잔액`, `공문 정리`, `준공 서류`, `보험`, `초과근무` 같은 업무 표현으로 찾을 수 있게 했습니다.
- 자주 쓰는 검색 예시를 바로 누를 수 있는 버튼으로 제공합니다.
- 검색 아래에 업무군 바로가기를 추가했습니다.

### 기존 기능 유지

- 작은책상 할 일 자동 저장
- 빠른 메모 자동 저장
- 뽀모도로 집중 타이머
- 금액 한글 변환

- 모바일 반응형 UI
